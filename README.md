# 食安崇明 · 食品药品智慧监管与公众共治平台

面向崇明区食品药品安全委员会办公室场景的**前端演示原型**，覆盖「农村集体聚餐备案」「外卖骑手吹哨」「政策与办事指南」三条业务线，并提供乡镇与区级监管视角。

> 本仓库为源码备份与后续开发基线。仓库内容包含公司项目源码与原始示例记录，**保持私有，不对外公开**。

## 角色与业务流转

顶部栏可切换视角，切换只改变观察视角，不覆盖当前用户数据：

- **公众用户端**：政策查询、办事指南、家宴申报、吹哨上报、共治积分
- **外卖先锋骑手端**：骑手认证、食品安全线索上报
- **乡村办宴一条龙团队**：团队认证与积分
- **乡镇监管审核端**：按属地网格审核家宴申报与吹哨线索
- **区食药安办全局监管**：全区汇总与监管大屏

关键流转：

1. 居民申报家宴 → 乡镇待办通知 → 审核处置（通过／核查／驳回／整改）
2. 骑手或公众吹哨 → 乡镇受理与转派 → 执法核查 → 核实结案并发放积分与奖励
3. 团队违规扣分，低于阈值暂停资格

## 数据说明

- **无后端服务**：全部业务数据保存在浏览器 `localStorage`，键名前缀 `cm_food_safety_`。
- 首次读取缺失数据时以 `src/data/mockData.ts` 的初始值写入；该文件中的姓名、电话、地址与业务记录为**原始示例数据，真实性未核实**，公开或演示前需先审查脱敏。
- 数据只存在于当前浏览器，**清理浏览器存储即丢失**，跨设备不同步。
- 「重置演示数据」调用 `localStorage.clear()`，会清空该 origin 下的全部本地存储，请勿在存有其他数据的站点上使用。
