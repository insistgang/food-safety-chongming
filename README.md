# 食安崇明 · 食品药品智慧监管与公众共治平台

面向崇明区食品药品安全委员会办公室场景的**前端演示原型**，覆盖「农村集体聚餐备案」「外卖骑手吹哨」「政策与办事指南」三条业务线，并提供乡镇与区级监管视角。

> 本仓库为源码备份与后续开发基线。仓库内容包含公司项目源码与原始示例记录，**保持私有，不对外公开**。

## 快速开始

```bash
npm install
npm run dev        # 本地开发
npm run build      # 产出 dist/
npm run preview    # 预览构建产物
```

构建流程：TypeScript 类型检查 → Vite 打包 → 复制 200.html 静态页。

## 角色与业务流转

顶部栏可切换视角，切换只改变观察视角，不覆盖当前用户数据：

- **公众用户端**：政策查询、办事指南、家宴申报、吹哨上报、共治积分
- **外卖先锋骑手端**：骑手认证、食品安全线索上报
- **乡村办宴一条龙团队**：团队认证与积分
- **乡镇监管审核端**：按属地网格审核家宴申报与吹哨线索
- **区食药安办全局监管**：全区汇总与监管大屏

导航模块：综合总览、安心家宴、食药吹哨、政策宝典、办事指南、食安新语；**审核处置中心、监管大屏、平台管理配置**仅监管视角可见。

关键流转：

1. 居民申报家宴 → 乡镇待办通知 → 审核处置（通过／核查／驳回／整改）
2. 骑手或公众吹哨 → 乡镇受理与转派 → 执法核查 → 核实结案并发放积分与奖励
3. 团队违规扣分，低于阈值暂停资格

### 安心家宴的菜单核验与承诺书

申报时输入聚餐菜单，系统按关键词实时核验**高风险禁令食材**（如野生菌、未煮熟四季豆等），命中后在表单内给出高危警示；提交前必须阅读并签署《食品安全核心禁令承诺书》，需滚动阅读到底后按钮才可提交。实现位于 `src/components/banquet/BanquetModule.tsx` 与 `SafetyModal.tsx`。

## 数据说明

- **无后端服务**：全部业务数据保存在浏览器 `localStorage`，键名前缀 `cm_food_safety_`。
- 首次读取缺失数据时以 `src/data/mockData.ts` 的初始值写入；该文件中的姓名、电话、地址与业务记录为**原始示例数据，真实性未核实**，公开或演示前需先审查脱敏。
- 数据只存在于当前浏览器，**清理浏览器存储即丢失**，跨设备不同步。
- 「重置演示数据」调用 `localStorage.clear()`，会清空该 origin 下的全部本地存储，请勿在存有其他数据的站点上使用。
- 监管大屏支持导出「全区综合监管数据台账」CSV（带 UTF-8 BOM，便于 Excel 打开）。

## 已知边界

- 示例图片使用外部图床地址（Unsplash），**离线或断网环境会显示占位图**；演示前需预留网络或替换为本地资源。
- 组件内直接内联了少量示例记录与图片引用，如需对外演示应先做一次脱敏整理。
- 尚未接入随申办等外部体系；相关技术难点与改造方案已形成技术报告，**保留在本机、未纳入版本库**。
- 本仓库未包含端到端测试，也未做完整业务验收；表单中的默认值（如举办人、联系电话、地址、菜单）仍是示例内容。
